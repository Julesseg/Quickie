# Logo 1 app icon study

Question: which treatment of `~/Downloads/Logo 1.svg` should become Quickie's next app icon?

Open `index.html` to switch among A (Outline), B (Folded paper), and C (Launch ribbon). The `?variant=a`, `?variant=b`, and `?variant=c` URLs reopen a specific choice. Each direction has a 1024 px square PNG and an editable SVG. iOS supplies its own rounded icon mask; the preview applies a mask only for evaluation.

This is disposable prototype work. No app asset catalog or brand token has been changed. The selected direction needs a production pass after feedback.
